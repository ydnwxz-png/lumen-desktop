## 1.4.0
- Lumen Bot ставится везде: Ubuntu, Debian, Fedora, CentOS/RHEL, Arch, openSUSE, Alpine — с root и **без root** (общий хостинг, свой ПК)
- Windows: `start-bot.bat` + `bot-autostart.bat` (запуск вместе с Windows)
- Linux / macOS на своём ПК: `start-bot.sh` / `start-bot.command`, фоновый режим `bot/run.sh`
- Команда `lumen-bot` на сервере: status, logs, restart, setup, update, uninstall
- В релизах отдельный лёгкий архив `Lumen-Bot-x.x.x.zip` — только бот, без приложения
- Node.js качается один раз на весь компьютер (общий для приложения, бота и новых версий); находит уже установленный; не качает заново после сбоя распаковки
- В шапке чата — аватарка собеседника и полное название лота, который он смотрит

## 1.3.0
- **Lumen Bot** — автоматика FunPay на сервере с управлением через Telegram: вход по паролю, уведомления, ответы покупателям прямо из Telegram, установка на Ubuntu одной командой, Windows (`start-bot.bat`), Docker
- **Автоматика как у FunPay Cardinal** — в боте и в приложении: автовыдача товаров, автоответы на команды, приветствие, ответы на отзывы, спасибо за подтверждение, напоминание подтвердить, восстановление лотов, чёрный список, автоподнятие
- **Плагины** — один файл `.js`, работают и в боте, и в приложении; примеры и документация в `docs/PLUGINS.md`
- В приложении новая вкладка «Автоматика» и переключатель «где работает автоматика» (на этом ПК / в Lumen Bot / выключена)
- Старые автоответы из настроек заменены новой автоматикой
